# 在线行业调研工作流实施计划

## 1. Provider 适配层

- 增加环境变量和 Streamlit Secrets 配置读取。
- 封装 Tavily 搜索和 Dify Workflow blocking API。
- 统一 URL 规范化、日期解析、输出解析和重试策略。

## 2. 本地研究项目

- 在线任务创建时写入项目范围和固定七维问题。
- 保持问题未批准状态，确保人工范围确认仍是首个门禁。
- 调整问题读取顺序，保证页面显示顺序与框架定义一致。

## 3. 自动检索与证据落库

- 每个维度生成中英文查询，调用 Tavily 并去重来源。
- 持久化来源元数据和候选证据。
- 可选调用 Dify 证据工作流；失败时降级为原文摘录并保留风险标记。

## 4. 工作台交互

- 首页增加在线研究任务表单。
- 资料来源页增加检索状态、配置提示、部分失败反馈。
- 研究简报页优先调用 Dify 正式简报工作流，未配置时使用本地生成器。

## 5. 验证

- 测试查询生成、URL 去重、Dify 请求协议、项目持久化和模拟检索落库。
- 运行全量 pytest 与 Ruff。
- 保持 Streamlit 8512 端口服务可复用，供本地浏览器直接打开。
